# 🧠 Mental Health Condition Score Prediction using Machine Learning

![Python](https://img.shields.io/badge/Python-3.10-blue?logo=python)
![ML](https://img.shields.io/badge/Machine%20Learning-Linear%20RandomForestClassifier-orange)
![Streamlit](https://img.shields.io/badge/Streamlit-Web%20App-red?logo=streamlit)
![Status](https://img.shields.io/badge/Status-Completed-success)

An **End-to-End Machine Learning Web Application** that predicts an individual's **Mental Health Condition Score** based on lifestyle, psychological, and demographic factors.

The application is built using **Python**, **Scikit-learn**, and **Streamlit**, featuring an interactive user interface for real-time mental health score prediction.

---

## 📊 Model Performance

Three machine learning models were trained and evaluated.

| Model | Cross Validation Accuracy |
|--------|--------------------------:|
| Logistic Regression | **92%** |
| Support Vector Machine (SVM) | **92%** |
| Random Forest Classifier | **99%** ✅ |

🏆 **Selected Model:** Random Forest Classifier

The Random Forest model achieved the highest accuracy and overall performance after hyperparameter tuning and cross-validation, making it the final model used for deployment.
